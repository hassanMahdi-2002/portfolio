# Hassan Mahdi - Personal Portfolio 🚀

A responsive, interactive, and modern personal portfolio website built to showcase my journey as a Computer Engineer and my professional projects as a Full-Stack Web & Mobile App Developer.

## 🔗 Live Demo
**[Click here to view the live portfolio](https://hassanMahdi-2002.github.io/portfolio/)**

## ✨ Features
* **Modern UI/UX:** Clean, professional dark-themed design.
* **Smooth Animations:** Beautiful scroll-triggered animations using AOS.
* **Dynamic Interactions:** Custom sticky navigation and smooth scrolling implemented with JavaScript & jQuery.
* **Fully Responsive:** Optimized for all screen sizes (Mobile, Tablet, Desktop) using Bootstrap's grid system.
* **Integrated Resume:** Direct download link for my latest ATS-friendly CV.

## 🛠️ Built With
* **HTML5 & CSS3**
* **JavaScript (ES6) & jQuery**
* **Bootstrap 5** (CSS Framework)
* **AOS Library** (Animate On Scroll)
* **FontAwesome** (Icons)
